Name That Tune

This game plays songs from your Spotify Premium account. Spotify asks every personal app to register once, which takes a few minutes.

  1. Open developer.spotify.com/dashboard, log in with your Premium account and choose Create app. Any name and description will do.
  2. In the Redirect URIs box, add this exact address:
  3. Where it asks which APIs you plan to use, tick Web API and Web Playback SDK, then save.
  4. Open the app's settings, copy the Client ID and paste it here.

Only the account that created the app can log in. To let someone else use their own Spotify, add them under User Management in the dashboard.

Pick a category

    Type a genre, a decade, a year or an artist. You can also paste a link to one of your own Spotify playlists. If a name could be either, start it with "artist:" or "genre:".
